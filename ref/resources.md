### Useful Resources
- [Exploit-DB](https://www.exploit-db.com/) - Archive of exploits and vulnerable software with searchable database
- [Rapid7 Vulnerability Database](https://www.rapid7.com/db/) - Comprehensive vulnerability and exploit intelligence
- [GTFOBins](https://gtfobins.github.io/) - Unix binaries that can be used for privilege escalation and bypassing security restrictions
- [LOLBAS](https://lolbas-project.github.io/) - Windows binaries for living off the land and bypassing application whitelisting
- [PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings) - Collection of useful payloads and bypass techniques for web application security
- [HackTricks](https://book.hacktricks.xyz/) - Comprehensive penetration testing methodology and techniques wiki
- [MITRE ATT&CK](https://attack.mitre.org/) - Knowledge base of adversary tactics and techniques based on real-world observations
